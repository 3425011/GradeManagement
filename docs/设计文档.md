# 班级学生成绩管理网站 — 项目设计文档

> 技术栈：Java Servlet + JSP + MySQL + JDBC（MVC 分层，不使用框架）
> 前端：Bootstrap 5 + ECharts 5 + JSTL
> 服务器：Tomcat 9.x

---

## 一、项目介绍与业务流程图

### 1.1 项目概述

本项目是一个基于 **Java Servlet + JSP** 的班级学生成绩管理网站，采用经典的 **MVC 三层架构**（表现层 JSP / 控制层 Servlet / 业务层 Service / 数据访问层 DAO），纯 JDBC 访问 MySQL，不依赖任何框架。系统面向 **教师** 与 **学生** 两类角色，实现成绩的录入、查询、修改、删除、批量导入导出、统计分析与可视化，并加入多学期成绩趋势、操作日志追溯、权限严格隔离、数据校验等智能增强功能。

### 1.2 技术栈

| 层次 | 技术选型 |
|------|----------|
| 表现层 | JSP + JSTL + Bootstrap 5 + ECharts 5 |
| 控制层 | Servlet |
| 业务层 | Service（Java） |
| 数据访问层 | DAO + JDBC（PreparedStatement 防注入） |
| 数据库 | MySQL 8.0（utf8mb4） |
| 服务器 | Tomcat 9.x |
| 构建工具 | Maven（依赖：mysql-connector、jstl、servlet-api、poi） |

### 1.4 核心业务流程说明

**教师端流程：**
1. 登录 → 进入教师工作台（展示班级统计卡片：学生数、科目数、成绩记录数）
2. 成绩管理 → 按「班级/科目/学期/分数区间/姓名学号模糊搜索」筛选成绩列表（分页）
3. 录入成绩 → 表单校验（非空、0~100 区间、学生是否存在、重复成绩拦截）→ 保存 → 写日志
4. 修改/删除成绩 → 权限校验 → 更新 → 写日志（删除需二次确认）
5. Excel 批量导入 → 上传解析 → 逐行校验 → 事务批量插入（失败整体回滚）
6. 批量导出 → 按当前筛选条件生成 xlsx → 下载
7. 统计分析 → 单科平均分/及格率/优秀率/方差/最高最低分 → ECharts 柱状图 + 低分预警标红
8. 操作日志 → 查看所有教师操作的追溯记录

**学生端流程：**
1. 登录 → 进入学生工作台（展示本人成绩概览）
2. 查看本人各科成绩（仅本人数据，按学期筛选）
3. 查看成绩趋势（同一科目多学期对比，折线图）
4. 查看个人统计（平均分、排名、低分预警）

## 二、角色权限说明

| 功能 | 教师 (teacher) | 学生 (student) | 未登录 |
|------|:-------------:|:-------------:|:------:|
| 查看本人成绩 | ✅ | ✅ | ❌ |
| 查看全班/他人成绩 | ✅ | ❌（严格隔离） | ❌ |
| 录入成绩 | ✅ | ❌ | ❌ |
| 修改成绩 | ✅ | ❌ | ❌ |
| 删除成绩 | ✅ | ❌ | ❌ |
| Excel 批量导入 | ✅ | ❌ | ❌ |
| Excel 批量导出 | ✅ | ❌ | ❌ |
| 成绩筛选/模糊搜索 | ✅ | ❌ | ❌ |
| 统计分析/图表 | ✅ | ✅（仅个人） | ❌ |
| 成绩趋势 | ✅ | ✅（仅个人） | ❌ |
| 操作日志查看 | ✅ | ❌ | ❌ |

**权限隔离实现方式：**
- 登录拦截：`LoginFilter` 校验 Session，未登录访问任何页面跳转登录页
- 角色拦截：`PermissionFilter` 校验 URL 前缀 `/teacher/*` 仅教师可访问，`/student/*` 仅学生可访问
- 数据级隔离：学生查询成绩时，SQL 强制拼接 `WHERE student_id = 当前登录学生id`，后端从 Session 取 id 而非前端传参，**杜绝越权查看他人成绩**
- 教师全部权限通过 `role = 'teacher'` 判断

## 三、数据库表结构（MySQL 建表语句）

```sql
-- =====================================================
-- 班级学生成绩管理系统 数据库设计
-- 数据库名: grade_management   字符集: utf8mb4
-- =====================================================
CREATE DATABASE IF NOT EXISTS grade_management
  DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
USE grade_management;

-- -----------------------------------------------------
-- 1. 用户表 t_user（教师 + 学生共用）
-- -----------------------------------------------------
CREATE TABLE t_user (
  id          INT          NOT NULL AUTO_INCREMENT COMMENT '主键',
  username    VARCHAR(50)  NOT NULL                COMMENT '登录账号(唯一)',
  password    VARCHAR(64)  NOT NULL                COMMENT '密码(MD5/SHA加密存储, 不存明文)',
  real_name   VARCHAR(50)  NOT NULL                COMMENT '真实姓名',
  role        VARCHAR(20)  NOT NULL DEFAULT 'student' COMMENT '角色: teacher=教师 student=学生',
  student_no  VARCHAR(30)  DEFAULT NULL            COMMENT '学号(仅学生, 唯一, 用于重复拦截)',
  class_name  VARCHAR(50)  DEFAULT NULL            COMMENT '班级(如: 软件2101班)',
  create_time DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  PRIMARY KEY (id),
  UNIQUE KEY uk_username    (username),
  UNIQUE KEY uk_student_no  (student_no)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表';

-- -----------------------------------------------------
-- 2. 科目表 t_subject
-- -----------------------------------------------------
CREATE TABLE t_subject (
  id           INT         NOT NULL AUTO_INCREMENT COMMENT '主键',
  subject_name VARCHAR(50) NOT NULL                COMMENT '科目名称',
  subject_code VARCHAR(30) DEFAULT NULL            COMMENT '科目编码',
  create_time  DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  UNIQUE KEY uk_subject_name (subject_name)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='科目表';

-- -----------------------------------------------------
-- 3. 成绩表 t_grade（含学期字段, 支持多学期趋势对比）
-- -----------------------------------------------------
CREATE TABLE t_grade (
  id          INT          NOT NULL AUTO_INCREMENT COMMENT '主键',
  student_id  INT          NOT NULL                COMMENT '学生ID(关联t_user.id)',
  subject_id  INT          NOT NULL                COMMENT '科目ID(关联t_subject.id)',
  score       DECIMAL(5,1) NOT NULL                COMMENT '成绩 0~100',
  semester    VARCHAR(20)  NOT NULL                COMMENT '学期(如 2025-2026-1)',
  exam_type   VARCHAR(20)  DEFAULT '期末'           COMMENT '考试类型: 期中/期末/平时',
  create_time DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  update_time DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  UNIQUE KEY uk_stu_sub_sem (student_id, subject_id, semester, exam_type) COMMENT '同一学生同科同学期同类型唯一, 拦截重复成绩',
  KEY idx_student  (student_id),
  KEY idx_subject  (subject_id),
  KEY idx_semester (semester),
  CONSTRAINT fk_grade_student FOREIGN KEY (student_id) REFERENCES t_user(id)    ON DELETE CASCADE,
  CONSTRAINT fk_grade_subject FOREIGN KEY (subject_id) REFERENCES t_subject(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='成绩表';

-- -----------------------------------------------------
-- 4. 操作日志表 t_operation_log
-- -----------------------------------------------------
CREATE TABLE t_operation_log (
  id          INT          NOT NULL AUTO_INCREMENT COMMENT '主键',
  user_id     INT          NOT NULL                COMMENT '操作人ID',
  username    VARCHAR(50)  NOT NULL                COMMENT '操作人账号',
  real_name   VARCHAR(50)  DEFAULT NULL            COMMENT '操作人姓名',
  operation   VARCHAR(20)  NOT NULL                COMMENT '操作类型: ADD/MODIFY/DELETE/IMPORT/EXPORT/LOGIN',
  target      VARCHAR(100) DEFAULT NULL            COMMENT '操作对象描述(如: 学生姓名+科目)',
  detail      VARCHAR(500) DEFAULT NULL            COMMENT '操作详情(改动前后内容/导入条数等)',
  ip          VARCHAR(50)  DEFAULT NULL            COMMENT '操作IP地址',
  create_time DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '操作时间',
  PRIMARY KEY (id),
  KEY idx_user        (user_id),
  KEY idx_operation   (operation),
  KEY idx_create_time (create_time)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='操作日志表';
```

**分层职责与调用关系：**

```
JSP (表现层)
  │ 表单提交 / AJAX请求
  ▼
Filter (登录/权限拦截) → Servlet (控制层，参数接收与校验)
  │
  ▼
Service (业务层：业务规则、事务、统计计算)
  │
  ▼
DAO (数据访问层：PreparedStatement 执行SQL)
  │
  ▼
MySQL (数据库)
```

## 六、期末答辩亮点说明

### 6.1 架构设计亮点

1. **纯 Servlet + JSP 手写 MVC**：不用框架，完整展示 MVC 分层思想，答辩时能讲清"为什么分层、每层干什么"
2. **PreparedStatement 防 SQL 注入**：所有 SQL 参数化，这是面试/答辩高频考点
3. **过滤器实现权限控制**：LoginFilter + PermissionFilter 双层拦截，体现 AOP 思想
4. **事务控制**：批量导入使用 JDBC 事务，失败整体回滚，保证数据一致性

### 6.2 智能增强功能亮点（对应加分项）

| 加分项 | 实现要点 | 答辩强调点 |
|--------|----------|-----------|
| 成绩智能分析 | 平均分/及格率/优秀率/方差/最高最低分，SQL 聚合 + Java 计算 | 方差体现统计学基础，SQL `GROUP BY` 聚合 |
| 批量导入导出 | Apache POI 解析/生成 xlsx，事务批量插入，逐行校验 | 大文件解析、错误行定位、模板下载 |
| 筛选与查询 | 多条件动态拼接 SQL（WHERE 1=1），LIKE 模糊搜索 | 动态 SQL 拼接的安全写法 |
| 成绩趋势 | 成绩表加 semester 字段，折线图展示多学期对比 | 表结构设计前瞻性 |
| 权限严格隔离 | 后端从 Session 取学生 id 拼 WHERE，杜绝前端伪造参数越权 | 数据级权限，安全面试题 |
| 数据校验 | 前后端双重校验，0~100 区间、重复学号 UNIQUE、重复成绩联合唯一键 | 数据库约束 + 应用层校验双保险 |
| 日志记录 | 增删改自动写 t_operation_log，含 IP、改动前后值 | 可追溯性、审计思想 |
| 可视化 | ECharts 柱状图/折线图，低分标红 | 前端数据可视化 |

### 6.3 技术细节加分点（答辩可展开）

- **密码加密存储**：MD5 加密（可进一步说加盐、BCrypt）
- **分页封装**：PageBean 通用分页，解决大数据量性能
- **AJAX + JSON**：统计图表用 Servlet 返回 JSON 给 ECharts，体现前后端分离思想
- **JSTL + EL 输出**：`c:out` 防 XSS
- **Session 会话管理**：登录状态保存、退出销毁

### 6.4 可能的答辩提问与应对

1. **"为什么用 PreparedStatement？"** → 防 SQL 注入 + 预编译性能
2. **"如何防止学生看别人成绩？"** → 后端从 Session 取 id 拼 WHERE，不信前端参数
3. **"批量导入一半失败怎么办？"** → 事务回滚，全部成功或全部失败
4. **"方差怎么算？"** → Σ(x-均值)²/n，展示统计知识
5. **"数据库表为什么这么设计？"** → 成绩表存 student_id/subject_id 外键，符合第三范式，避免数据冗余
